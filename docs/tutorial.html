A tour for your first session

Getting started with Marmota

Marmota is a terminal file manager that works beside your Claude Code and Codex sessions; you start it with y. You browse files on top; at the foot you see every session that runs, what each one is doing, and you can write to any of them without leaving your files.

You need a Mac, WezTerm (y opens sessions in its panes), and Claude Code, the Codex CLI, or both.

1

Install it and start it

# the first time, build.sh installs everything: Go, WezTerm, a Nerd Font, the y command
git clone https://github.com/junjieliang672/marmota.git
cd marmota
./build.sh

# then, in a new terminal (WezTerm)
y

build.sh builds the program into bin/y, adds a short block to your shell config that puts it on your PATH, and gives WezTerm its look: the pane you type in stays bright and a blue edge marks it. Run ./build.sh again whenever you pull new changes; it keeps your settings and adds any new ones.

2

What is on the screen

A ╭ Marmota 3/9 ▌ build.sh CLAUDE.md README.md ✳ src/ ✳2
B ╭ README.md # Marmota A terminal file manager that works beside your Claude Code and Codex sessions.
C ╭ ✳ Sessions 1 ✳ cc fix the login Edit(login.go) 2 ⚑ co docs pass asks: run make docs
D ╭ Details FILE README.md · 4 KB MAC cpu ▮▮▯▯ mem ▮▮▮▯ OPS nothing running
E ╭ Ask → fix the login K write you: "tests too?"
K:ask @:send !:sessions >:agent ?:help✳ 1 working · ⚑ 1 needs you
A

File panels. Your folders. tab moves to the next panel, n opens another. A ✳ marks a file a running session changed.

B

Preview. The file under the cursor; while you are in the Sessions box, the selected session's conversation.

C

Sessions box. Every running session, cc for Claude Code and co for Codex. ! goes in and out.

D

Details. The file, your Mac's cpu, memory and disk, and file operations under way. M focuses it.

E

Ask box. Where you write to a session, or start a new one. K opens it.

F

Status line. The keys you can press now, and how many sessions are working, need you or have unread replies. F hides the boxes at the foot.

4

Start a session beside your files

Press > for Agent mode and type one of these; the session opens in a WezTerm pane next to Marmota, in the folder you are in.

claudeClaude Code
claude rcClaude Code with Remote Control on, so you can follow it from your phone
codexThe Codex CLI

Press @ in a file panel to type the selected files into that session as mentions, then switch to its pane and say what to do with them.

5

Keep an eye on your sessions

Press !. The Sessions box takes the keyboard and lands on the session that most needs you. Each row shows how the session stands, which program it runs in, its name and its age; the line under it says what it is doing.

✳WorkingIt is replying or running a tool.
⚑Needs youIt asks for a permission or an answer.
●UnreadIt replied since you last looked.
○WaitingIt is idle, ready for your next prompt.
In the Sessions boxWhat it does
j k · enterMove between sessions · show the session's pane beside Marmota
W · ] [The files this session changed · the next and previous change in the preview's diff
VPin the preview to this session while you browse files
r · w · xRename · fork into a new git worktree · stop (it asks first)
m · nMention this Claude Code session in the Ask box (Codex sessions have no name to mention) · write to a new session
! or escBack to your files
6

Ask without leaving your files

Press K. What you write goes to the session the Sessions box is on: typed into a Claude Code session's prompt, or sent to Codex, which runs it after what it is doing. On a new session (n in the Sessions box, or a folder with none), sending starts one in the background and keeps the keyboard with you.

In the Ask boxWhat it does
enterSend
tabFor a new session: Claude Code or Codex (Claude Code unless you switch)
ctrl+o · ctrl+tThe model · the effort (medium unless you choose). For a running Codex session they change from your next message.
shift+tabThe permission mode a new session runs in: bypass, accept edits, auto, plan or manual
↑ ↓ · ctrl+uYour earlier messages to this session · clear what you wrote
escClose the box; your draft stays for next time

In a file panel, m adds the file under the cursor (or the selection) to your draft, so the session knows exactly which file you mean.

7

Answer a session that needs you

When a session asks something, its row shows ⚑, the status line counts it, and the preview shows the question as the session draws it, options included. Press K and your keys go to that question: y, enter, the arrows, esc, whatever it takes. ctrl+k gives the keyboard back to the list.

8

Make it yours

  • y path-list prints where your settings live, usually ~/.config/marmota.
  • config.toml: your editor, theme, preview settings, codex_command, and cd_on_quit (your shell moves to the folder you quit in).
  • hotkeys.toml: every key. If you prefer Vim keys, copy src/superfile_config/vimHotkeys.toml over it.
  • Themes: set theme to the name of any file in the theme folder.
